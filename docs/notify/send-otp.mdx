# Send OTP

`POST /send/otp`

Generates a cryptographically secure 6-digit passcode and sends it to the specified email address. No branding, just the code.

---

## Endpoint

```http
POST /send/otp
```

---

## What recipients see

![OTP email example](https://raw.githubusercontent.com/lifygo/lifygo/main/images/otp.png)

---

## Request

```bash
curl -X POST http://localhost:8080/send/otp \
  -H "X-API-Key: lfy_your_key" \
  -H "Content-Type: application/json" \
  -d '{"to":"hello@example.com"}'
```

---

## Request Body

| Field | Type | Required | Description |
|------|------|:--------:|-------------|
| `to` | `string` | Yes | Recipient email address |

---

## Response

**HTTP 200 OK**

```json
{
  "email": "hello@example.com",
  "expires_at": "2026-08-04T09:40:00Z"
}
```

---

## Behavior

- 6-digit numeric codes generated with `crypto/rand`
- Stored in Redis with 10 minute TTL
- One active OTP per email at a time
- Single use — deleted immediately after verification

---

## Errors

| Status | Description |
|:------:|-------------|
| 400 | Missing required field |
| 401 | Invalid or missing API key |
| 500 | Delivery failed |
